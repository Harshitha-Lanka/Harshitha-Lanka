## 🚀 Featured Projects

### 🥗 C³ App – Food Detection and Calorie Estimation

Developed an AI-powered health-tech application that detects food items from images using **YOLOv8** and estimates calorie values using **Random Forest and XGBoost regression models**. The system integrates nutrition data, image-based food recognition, calorie prediction, visual breakdowns, and CSV export to provide users with an interactive food intake analysis experience.

**Key Highlights**
- Built an end-to-end pipeline from food image upload to calorie and nutrition result generation.
- Used **YOLOv8** for food item detection from uploaded meal images.
- Applied **Random Forest** and **XGBoost** models for calorie estimation.
- Integrated nutrition reference data to map detected food items with calorie values.
- Designed an interactive interface with confidence score, calorie breakdown, chart visualization, and CSV download.

**Tech Stack:** Python, YOLOv8, Machine Learning, Random Forest, XGBoost, FastAPI, React.js
